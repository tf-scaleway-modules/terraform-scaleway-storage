## Why

Planning in this module relied on Agent OS (`agent-os/standards/`, `.claude/commands/agent-os/`), an unversioned copy of rules that are now published as pinned OpenSpec stores (`quality`, `repository`, `terraform`). Agent OS is replaced by the referenced stores: the module adopts OpenSpec so that `openspec/specs/` records the current contract and future behaviour changes are planned as change proposals against it.

## What Changes

- Remove Agent OS: `agent-os/standards/` and `.claude/commands/agent-os/`. Nothing is ported; the standards are replaced by the `quality`, `repository` and `terraform` stores.
- Configure `openspec/config.yaml` (stores pinned to a tag, module `context`, per-artifact `rules`, `operations` guidance) and add `AGENTS.md` and `CLAUDE.md`.
- Install the `openspec-*` skills for Claude Code (`.claude/skills/`) and OpenCode (`.opencode/skills/`).
- Pin `node` and the `openspec` CLI in `mise.toml`, add the `spec-validate` and `spec-setup` tasks and `scripts/openspec-setup.sh`, and validate specs in CI with the `validate:specs` job (`.gitlab/specs.yml`, `OPENSPEC_VERSION` in `.gitlab/global.yml`).
- Write the baseline capability specs describing the module as released today.
- Update the README "Contributing" section with the OpenSpec workflow.
- `CHANGELOG.md` stays generated by git-cliff from commit subjects.
- No change to any `.tf` file, input, output or resource: semver **patch**. Nothing new lands in state.

## Capabilities

### New Capabilities
- `module-contract`: OpenTofu/Terraform and provider constraints, no provider/backend blocks, project lookup, global inputs, tag merging, and the outputs that expose the module.
- `buckets`: Object Storage buckets, count expansion, versioning, ACL, default server-side encryption, lifecycle rules, CORS and static website hosting.
- `bucket-access-and-lock`: bucket policies and object lock (WORM) configurations.
- `objects`: objects uploaded from a local file or inline content.
- `block-volumes`: Block Storage volumes with count expansion.
- `block-snapshots`: Block Storage snapshots from a volume or imported from Object Storage, with QCOW2 export.
